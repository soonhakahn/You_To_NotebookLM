YouTube → NotebookLM

재생목록 링크를 붙여넣으면 모든 영상 URL을 NotebookLM에 붙여넣을 수 있게 묶어 드립니다.

설정 (YouTube API 키 · 묶음 크기)

재생목록 조회에 필요합니다. 키는 이 기기 브라우저에만 저장됩니다. 발급: Google Cloud Console → API 및 서비스 → “YouTube Data API v3” 사용 설정 → 사용자 인증 정보 → API 키.

한 노트북의 소스 수 한도는 요금제에 따라 다릅니다(무료 50개). 한도를 넘는 재생목록은 여러 노트북으로 나누세요.

NotebookLM 열기 ↗
NotebookLM에 넣는 방법
  1. 아래 묶음의 복사 버튼을 누릅니다.
  2. NotebookLM에서 노트북을 열고 + 소스 추가 → 웹사이트(또는 YouTube)를 선택합니다.
  3. 복사한 URL을 붙여넣고 삽입. 다음 묶음도 반복합니다.

여러 URL 동시 붙여넣기가 안 되는 화면이라면 묶음 크기를 “1개씩”으로 바꾸세요. 자막(캡션)이 없는 영상은 NotebookLM이 가져오지 못할 수 있습니다.
