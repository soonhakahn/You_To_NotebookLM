# 아이폰 단축어: YouTube → NotebookLM

YouTube 앱/사파리에서 **공유 → "NotebookLM에 보내기"** 를 누르면

- **동영상 하나**: URL을 클립보드에 복사하고 NotebookLM을 엽니다.
- **재생목록**: 재생목록 페이지를 읽어 **영상 URL 전체(최대 100개)** 를 줄바꿈으로 묶어 복사하고 NotebookLM을 엽니다.

NotebookLM에서 **+ 소스 추가 → 웹사이트(또는 YouTube)** 에 붙여넣고 **삽입**하면 끝입니다.

> iOS는 서명되지 않은 `.shortcut` 파일 설치를 막기 때문에 파일 대신 아래 순서대로 직접 만드는 방법을 안내합니다(약 5분).
> 만든 뒤 단축어를 길게 눌러 **공유 → iCloud 링크 복사** 하면 다른 기기에도 쉽게 설치할 수 있습니다.

## 만들기

**단축어 앱 → 오른쪽 위 `+` → 이름: `NotebookLM에 보내기`**
하단의 **ⓘ(세부사항)** 에서 **"공유 시트에서 보기"** 를 켭니다.

아래 동작을 순서대로 추가합니다. (괄호 안은 영어 iOS 표기)

| # | 동작 | 설정 |
|---|------|------|
| 1 | **공유 시트에서 입력 받기** (Receive input from Share Sheet) | 유형: **URL, 텍스트, Safari 웹 페이지**. 입력이 없으면: **클립보드 사용** |
| 2 | **URL 가져오기** (Get URLs from Input) | 입력: `단축어 입력` |
| 3 | **목록에서 항목 가져오기** (Get Item from List) | **첫 번째 항목** / 입력: `URL` → 변수 이름을 `영상주소`로 지정(길게 눌러 이름 변경) |
| 4 | **만약** (If) | `영상주소` **다음을 포함** `list=` |

### 4-A. "만약" 안쪽 (재생목록인 경우)

| # | 동작 | 설정 |
|---|------|------|
| 5 | **메뉴에서 선택** (Choose from Menu) | 질문: `무엇을 보낼까요?` / 항목: `재생목록 전체`, `이 영상만` |
| 6 | ▸ **`재생목록 전체`** 항목 안: **텍스트 일치** (Match Text) | 패턴: `list=([A-Za-z0-9_-]+)` / 입력: `영상주소` |
| 6-1 | **일치 항목의 그룹 가져오기** | **인덱스 1에 있는 그룹** |
| 6-2 | **텍스트** | `https://www.youtube.com/playlist?list=` 뒤에 `인덱스의 그룹` 삽입 |
| 6-3 | **URL의 콘텐츠 가져오기** (Get Contents of URL) | URL: 위 `텍스트` / 방법: GET / 헤더 추가: `Accept-Language` = `ko-KR` |
| 7 | **텍스트 가져오기** (Get Text from Input) | 입력: `URL의 콘텐츠` |
| 8 | **텍스트 일치** (Match Text) | 패턴(그대로 복사):<br>`"videoId":"([A-Za-z0-9_-]{11})","playlistId":"[^"]+","index":\d+`<br>대소문자 구분: 켬 |
| 9 | **각 항목을 반복** (Repeat with Each) | 입력: `일치 항목` |
| 10 | ▸ 반복 안: **일치 항목의 그룹 가져오기** (Get Group from Matched Text) | **인덱스 1에 있는 그룹**, 입력: `반복 항목` |
| 11 | ▸ 반복 안: **텍스트** (Text) | `https://www.youtube.com/watch?v=` 뒤에 변수 `인덱스의 그룹` 삽입 |
| 12 | **반복 종료** 다음: **텍스트 결합** (Combine Text) | 입력: `반복 결과`, 구분자: **새로운 줄** |
| 13 | **클립보드에 복사** (Copy to Clipboard) | 입력: `결합된 텍스트` |
| 14 | **개수 세기** (Count) | **항목** / 입력: `반복 결과` |
| 15 | **알림 보기** (Show Notification) | `개수`개 영상 URL을 복사했습니다. NotebookLM에서 붙여넣으세요. |
| 16 | ▸ **`이 영상만`** 항목 안: **텍스트 대치** (Replace Text) | 찾기: `&list=.*` / 대치: (비움) / **정규 표현식** 켬 / 입력: `영상주소` |
| 17 | **클립보드에 복사** | 입력: `업데이트된 텍스트` |
| 18 | **메뉴 종료** | |

### 4-B. "그렇지 않으면" (Otherwise, 동영상 하나인 경우)

| # | 동작 | 설정 |
|---|------|------|
| 19 | **클립보드에 복사** | 입력: `영상주소` |
| 20 | **만약 종료** (End If) | |

## 사용법

1. YouTube 앱에서 동영상 또는 재생목록을 열고 **공유 → 더보기 → NotebookLM에 보내기**
   (재생목록은 재생목록 화면의 `⋯` → **공유**)
2. NotebookLM이 열리면 노트북을 선택 → **+ 소스 추가** → **웹사이트**(또는 **YouTube**)
3. 붙여넣기 → **삽입**

## 알아둘 점

- **여러 URL 한 번에 붙여넣기**: NotebookLM의 URL 입력칸은 줄바꿈/공백으로 구분된 여러 URL을 받습니다.
  화면(버전)에 따라 한 번에 하나만 받는 경우엔 [웹앱](../README.md#2-웹앱)의 “1개씩” 묶음 모드를 쓰세요.
- **100개 제한**: 재생목록 페이지는 처음 100개 영상만 담고 있어서 단축어는 최대 100개까지 가져옵니다.
  더 긴 재생목록은 웹앱(YouTube API 키 사용)을 이용하세요.
- **노트북 소스 한도**: 무료 노트북은 소스 50개가 한도입니다. 12번과 13번 사이에
  **목록에서 항목 가져오기 → 범위 1~50** 을 넣으면 앞 50개만 복사합니다.
- **자막 필요**: NotebookLM은 캡션(자동 자막 포함)이 있는 **공개** 동영상만 가져옵니다.
  비공개/삭제 영상은 페이지에 나타나지 않거나 가져오기에 실패합니다.
- **"이 영상만"** 메뉴는 `watch?v=...&list=...` 처럼 재생목록 안의 영상을 공유했을 때만 의미가 있습니다.
  재생목록 화면(`playlist?list=...`)을 공유했다면 **재생목록 전체**를 고르세요.
- **믹스 재생목록**(`list=RD...`)은 자동 생성 목록이라 가져올 수 없습니다.

## (선택) 웹앱과 연결하는 단축어

YouTube API 키를 웹앱에 한 번 저장해 두었다면, 아래 3단계짜리 단축어로 100개가 넘는 재생목록도 처리할 수 있습니다.

1. **공유 시트에서 입력 받기** (URL, 텍스트)
2. **URL 인코딩** (URL Encode) — 입력: `단축어 입력`
3. **URL 열기** — `https://<내 GitHub 아이디>.github.io/You_To_NotebookLM/?url=` 뒤에 `URL 인코딩된 텍스트`

웹앱이 열리면서 자동으로 목록을 가져오고, 묶음별 **복사** 버튼이 나타납니다.
